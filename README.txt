UP AgencY — CONSENT (PWA, fonctionne hors-ligne)
================================================
Version UP AgencY du formulaire de consentement (thème ardoise + turquoise).

HÉBERGEMENT (comme la version DDC)
- Le plus simple : GitHub Pages (nouveau dépôt, ex. "up-consent") ou Netlify Drop.
- Mets ces fichiers à la racine, active Pages (branche main / root).
- Ouvre l'URL dans SAFARI sur l'iPhone -> Partager -> Sur l'écran d'accueil.
- Ensuite l'app fonctionne hors-ligne.

CONTENU
- index.html, manifest.webmanifest, service-worker.js
- icon-192/512, icon-512-maskable, apple-touch-icon (logo UP)

RÉGLAGES (bouton engrenage en haut) : Projet, Producteur (par défaut "UP AgencY"),
préfixe de référence. Enregistrés sur l'appareil.
